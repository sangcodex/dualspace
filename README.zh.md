# DualSpace

[English](README.md)

一个用于 macOS 应用**双开、多开**的工具。微信和 QQ 已完成专项兼容适配，也支持其他兼容应用。创建后的分身可以从 Finder 或 Dock 直接启动，退出 DualSpace 后仍可独立运行。

## 使用方法

适用于 **Apple Silicon（M 系列芯片），macOS 13 及以上**。

1. 打开下载的 DMG，将 **DualSpace.app** 拖入 **Applications（应用程序）**。
2. 打开 DualSpace，选择已安装的应用，或把 `.app` 拖入窗口。
3. 为分身命名并创建，启动后按需登录账号。
4. 需要多开时，再次选择同一个原版，用不同名称创建更多分身。

实例卡片会显示启动和运行状态。通过 **Show Copy in Finder** 找到分身，可将它拖到 Dock。左侧栏支持折叠，快捷键为 **Control-Command-S**。

应用尚未经过 Apple 公证。如被 macOS 拦截，请确认来源可信，再到**系统设置 → 隐私与安全性**中允许打开。

## 兼容说明

- **微信：**已专项适配，微信 4.1.15 分身的朋友圈已确认账号归属正确、操作正常。
- **QQ：**已专项适配，QQ 7.0.2 已验证与原版同时运行，具有独立进程、窗口和资料目录；账号登录尚未验证。
- **其他应用：**通用支持原生、Electron 和 Chromium 应用，Chrome 也已验证与原版同时运行。实际兼容性取决于应用及版本。

安装包仅包含 DualSpace，不包含第三方应用或账号资料，请自行安装原版应用。
