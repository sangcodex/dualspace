# 实例状态、侧栏与本地隐私

## 现状和目标

2026-10-17 实测：微信分身持续运行，但管理器显示待启动并误报启动退出。Foundation 把 App Translocation 的 `/private/var/folders/…` 标准化为 `/var/folders/…`，现有代码仍仅匹配前者；Bundle ID、实例标记、只读挂载、包与可执行文件 inode 检查均通过。需要兼容这两种路径拼写，继续保留原有身份校验，避免误操作原版或外部复制品。

实例卡片目前只有运行/待打开，监听跟随窗口销毁，启动期间没有逐实例反馈。目标是明确显示检查中、待启动、启动中、运行中、退出中、启动失败和副本缺失；卡片与菜单栏共用状态。左侧栏支持折叠和恢复，保留导航入口，记住用户选择。

`.local` 已忽略，但日志、安装包、资料备份被移到其他位置时仍可能暴露。公开验证文档含本机绝对路径与实例标识，应脱敏；原始诊断只留在忽略目录。没有 Git 仓库或远端，不初始化正式仓库，不上传数据。

## 方案与边界

复用 AppKit 的 NSWorkspace 事件、SwiftUI、Combine 和 Git 自身的忽略语义。原生接口已覆盖需求，不引入第三方依赖。AppModel 拥有监听和状态生命周期，界面只展示；注入窄运行接口便于验证启动、失败、退出和事件交错。启动立即进入进行中，实际观察到匹配进程后显示运行，短暂 exec 交接允许有界重试；正常事件和重新激活触发刷新，不做永久定时扫描。启动回调返回 PID 不作为唯一成功依据。退出失败保留可见反馈与真实运行状态，重试或外部成功启动后清除旧失败。

状态读取先于应用库加载；异步刷新防止旧结果覆盖新列表。观察器随模型释放取消，关闭主窗口后菜单栏仍更新。当前运行的微信无需重启，验证启动与退出使用本地 Cocoa 样例。

侧栏折叠为窄图标栏，顶部按钮、View 菜单及 Control-Command-S 可切换；按钮有辅助功能名称和提示，偏好存入本机设置。

扩充 `.gitignore` 覆盖运行目录、清单、账号数据库、日志、崩溃、截图、应用包、安装包、环境密钥及本地 IDE 状态。保留正常源码/配置文件可见。新增只读隐私检查脚本：使用项目忽略规则列出待分享文件；有 Git 时检查已跟踪和暂存内容，无 Git 时使用临时元数据，最后清理；输出文件名和问题类型，不输出匹配的隐私正文。文档中的个人路径、实例 ID 和局部证据 ID 改为占位符。

## 改动与验收

修改 InstanceRuntime、AppModel、MainView、菜单栏及 README 双语；增加必要的运行状态回归覆盖和隐私检查脚本。先用现有运行实例与 Cocoa 示例验证，再补自动测试。验收包括：微信实际运行能正确识别；从管理器和 Finder 启动、正常退出、失败反馈、关闭窗口后的状态更新；侧栏折叠后导航和恢复；忽略样本与待分享文件扫描；完整测试、release 构建与签名。

不读取聊天内容，不修改账号数据，不把进程运行等同于账号已登录。隐私检查覆盖当前文件和暂存内容，不声称清理未提供的远端或历史提交。构建产物含开发工作区位置，继续忽略；公开分发需使用标准储存构建。

## 接口依据

2026-10-17 查阅：

- Git [gitignore](https://git-scm.com/docs/gitignore)：忽略规则不影响已跟踪文件，因此扫描需要包含索引。
- Apple [NSWorkspace.didLaunchApplicationNotification](https://developer.apple.com/documentation/appkit/nsworkspace/didlaunchapplicationnotification)：应用事件在模型生命周期内监听。
- Apple [URL.standardizedFileURL](https://developer.apple.com/documentation/foundation/url/standardizedfileurl)：路径判断应使用一致标准化；具体 `/private/var` 别名行为以本机运行证据验证。

## 实施结果

已完成上述改动。补充边界测试发现：完整路径是否存在会影响 Foundation 保留哪一种系统别名，因此最终显式接受两个系统前缀，随后仍验证只读卷、包身份及 inode。没有放宽为只凭 Bundle ID 匹配。

真实 Cocoa 样例通过逐实例启动/退出、窗口之外的外部事件、失败与重试；管理器正确显示正在运行的微信，侧栏折叠与快捷键已实测。32 项自动测试通过。隐私检查同时验证当前无仓库场景和临时仓库中的暂存泄露场景；只输出文件名与类型。完整验收记录见 [verification](../verification.md)。
